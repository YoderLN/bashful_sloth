# Gen 1 Pokedex API Project

Work in progress, please excuse the mess

Current form is a flask app built on top of sqlite3 database
Current database is limited to Pokemon, Moves and Types

Future plans include Items, Move Lists, Locations and Trainers

# Currently Supported Endpoints

pokemon_by_name:
     ID, Name, Primary Type, Secondary Type, HP, Attack, Defense, Special and Speed

pokemon_by_number:
    ID, Name, Primary Type, Secondary Type, HP, Attack, Defense, Special and Speed

pokemon_by_type:
    ID, Name, Primary Type, Secondary Type, HP, Attack, Defense, Special and Speed

moves_by_type:
    ID, Name, Type, Power, Details
